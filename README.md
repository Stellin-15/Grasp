# Grasp

**Clone any repo. Understand every line. Make your first contribution.**

Grasp is a free, local-first, open-source CLI that turns any codebase (open source, legacy, inherited, or AI-written) into a deep, code-level explanation you can learn from: what every file and function does, how the logic inside it works, which frameworks the project uses and how, and what its CI/CD pipelines check. Then it helps you contribute.

> Status: early development (Phase 0, scaffold). Nothing usable yet. See [the project plan](<PROJECT_PLAN (Grasp).md>) for the roadmap.

## Principles

- **Any repo, any author.** Works on code you did not write.
- **Grounded.** Static facts first, LLM prose second, every claim cites file and line.
- **Non-invasive.** Studying a repo never modifies it.
- **Free and local-first.** No account, no telemetry. Uses the agent CLI you already have.

## Honest limits

Generated explanations can be wrong. Grasp labels what is static fact and what is generated prose, and verifies every citation, but it is a learning aid, not a source of truth.
